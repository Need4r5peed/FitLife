# FitLife

### Briefly about the program:
"FitLife - это консольный бот-фитнес-трекер, помогающий 
пользователю рассчитать полезные индексы для его здоровья."

### Developers:
Программа создана в учебных целях в рамках курса Практикума. 
Программу разработал Волгин С.

### How to use:
Для развёртывания программы достаточно иметь установленный 
интерпретатор Python. Перейдите в директорию нахождения fit_life.py, 
откройте в ней консоль и дайте команду "python fit_life.py" - для запуска.
